# F2 Diploma Project — Документація

B2B Sales Automation and Computer Vision-Based Inventory Recognition Information System for Food Establishments.

Навігаційний дашборд пояснювальної записки кваліфікаційної роботи. Документація ведеться за методологією Docs-as-Code: кожен розділ — окремий Markdown-файл у каталозі `/docs`, зміни фіксуються через feature-гілки та Pull Request.
