# Thesis Proposal

> Проєкт виконується у парі зі студенткою Островською Катериною Петрівною на основі спільно опрацьованої бізнес-ідеї («Інтелектуальна платформа перерозподілу товарів з обмеженим терміном придатності»). Відповідно до вимог щодо самостійності кваліфікаційних робіт, спільна ідея розділена на дві незалежні теми з окремою архітектурою, окремою логікою бази даних, окремим API та окремим клієнтським застосунком, що взаємно доповнюють одна одну через спільний контракт REST API, але виконуються та захищаються повністю самостійно.
>
> Тема партнерки: «Програмна система динамічного зіставлення попиту та геопросторової гейміфікації B2C-маркетплейсу» (мобільний застосунок, алгоритми ціноутворення, PostGIS). Тема, описана нижче, є другою, незалежною темою.

## 1. Попередня робоча назва проєкту

**Українською:** Інформаційна система автоматизації B2B-продажів та розпізнавання інвентарю закладів харчування засобами комп'ютерного зору

**English:** B2B Sales Automation and Computer Vision-Based Inventory Recognition Information System for Food Establishments

## 2. Актуальність та проблематика

Проблема харчових відходів є актуальним викликом для закладів харчування та роздрібної торгівлі: за оцінками галузевих досліджень, супермаркети та заклади HoReCa втрачають до 6% обороту через списання товарів з обмеженим терміном придатності. Існуючі цифрові рішення для перерозподілу надлишкової їжі (Too Good To Go, GoodMeal) розв'язують проблему лише з боку споживача, залишаючи невирішеною ключову операційну проблему бізнесу: персонал закладів не має часу наприкінці зміни вручну фотографувати, описувати та вносити кожну одиницю залишків у систему через адміністративну панель. Це створює суттєвий бар'єр входу для закладів-постачальників (supply-side friction) і обмежує масштабованість подібних платформ.

Інженерна проблема, яку вирішує дана робота, полягає у створенні B2B-інформаційної системи, що автоматизує процес формування торгових пропозицій (лотів) за допомогою розпізнавання зображень (комп'ютерного зору), а також надає закладам інструменти управління контентом, фінансової аналітики та обслуговування замовлень.

## 3. Сформована ідея продукту (тип архітектури)

Розробка B2B-інформаційної системи (мобільний застосунок + серверний мікросервіс) для адміністраторів та касирів закладів харчування, що є постачальниками товарів на маркетплейс перерозподілу продукції. Система реалізує мікросервісну архітектуру, що взаємодіє зі спільним B2C-маркетплейсом (розроблюваним паралельно) через REST API, водночас маючи власну незалежну базу даних, власну бізнес-логіку та власний клієнтський застосунок (мобільний B2B-застосунок для персоналу закладів).

Центральним інженерним компонентом системи є модуль **Snap & Sell** — інтеграція мультимодальної моделі комп'ютерного зору для автоматичного розпізнавання товарів на фотографії вітрини/залишків і генерації готових чернеток лотів для публікації. Обробка зображень виконується асинхронно через чергу фонових задач, що ізолює час відповіді API від латентності зовнішнього Vision API та підвищує стійкість системи до пікових навантажень.

## 4. Об'єкт, предмет, мета дослідження

**Об'єкт дослідження:** процес автоматизації управління продажами та обліком інвентарю закладів харчування в межах платформи перерозподілу товарів з обмеженим терміном придатності.

**Предмет дослідження:** методи та моделі розпізнавання об'єктів на зображеннях (комп'ютерного зору) для автоматизованого формування торгових пропозицій, а також архітектурні рішення побудови B2B-інформаційної системи.

**Мета роботи:** розробка інформаційної системи автоматизації B2B-продажів з інтегрованим модулем розпізнавання інвентарю на основі комп'ютерного зору, що скорочує час та трудовитрати персоналу закладів на формування торгових пропозицій.

**Завдання дослідження:**

1. Проаналізувати існуючі B2B-рішення для перерозподілу товарів та підходи до автоматизованого розпізнавання інвентарю.
2. Спроєктувати архітектуру мікросервісу B2B-платформи (REST API, структура бази даних, взаємодія з B2C-модулем, асинхронна обробка задач).
3. Розробити дизайн-систему (UI/UX) та реалізувати мобільний застосунок для адміністраторів і касирів закладів з розмежуванням екранів за ролями.
4. Інтегрувати модель комп'ютерного зору для розпізнавання товарів на фотографії та автоматичної генерації чернеток лотів і смарт-бандлів.
5. Реалізувати функціонал управління меню, лотами, категоріями та генерацію QR-кодів для видачі замовлень.
6. Розробити модуль фінансової аналітики для закладів (відновлений дохід, статистика списань) з кешуванням агрегованих метрик.
7. Налаштувати CI/CD-конвеєр (лінтинг, модульне й інтеграційне тестування, збірка Docker-образу) та провести тестування розробленого функціоналу.

## 5. Детальний опис функціоналу (Core Features)

1. **Snap & Sell** — розпізнавання товарів на фотографії вітрини/залишків за допомогою API комп'ютерного зору (OpenAI Vision API / Gemini Vision) з автоматичною генерацією чернеток лотів. Запит на обробку фотографії ставиться в чергу (BullMQ), клієнт отримує статус асинхронно.
2. Автоматична генерація смарт-бандлів (комбінованих пропозицій, наприклад «Круасан + кава») на основі розпізнаних позицій.
3. CRUD-управління меню, категоріями та лотами закладу (екрани адміністратора в мобільному застосунку).
4. Рольова модель доступу (адміністратор закладу / касир) з розмежуванням прав.
5. Генерація QR-кодів і сканування їх камерою телефону касира для підтвердження видачі замовлення клієнту.
6. Модуль фінансової аналітики: екран із картками показників відновленого доходу та кількості врятованих товарів і графіком динаміки продажів, з кешуванням у Redis.
7. Інтеграція з B2C-модулем через спільний REST API-контракт для публікації лотів на маркетплейсі.

## 7. Практичне значення

Отримані результати можуть бути використані закладами харчування та роздрібної торгівлі для скорочення трудовитрат на облік товарних залишків, зменшення обсягів списань та отримання додаткового джерела доходу від товарів з обмеженим терміном придатності. Розроблений модуль розпізнавання інвентарю та шаблон асинхронної обробки задач через чергу є придатними для повторного використання в інших задачах автоматизованого обліку товарів.
